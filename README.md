# CORY — Le coaching à ton rythme

Application web progressive (PWA) de coaching sportif en salle avec CORY, coach virtuelle.

- Ouvre l'adresse GitHub Pages dans Safari sur iPhone, puis Partager → « Sur l'écran d'accueil ».
- Fonctionne hors ligne après la première ouverture. Les données restent sur l'appareil (export/import dans Profil).
- Fichiers : `index.html` (toute l'app), `sw.js` (hors ligne), `manifest.webmanifest`, icônes, `img/` (expressions de CORY).

CORY ne remplace pas l'avis d'un professionnel de santé ou du sport.
